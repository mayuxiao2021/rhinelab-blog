# 设计系统 · 莱茵档案

> 本文是主题的「为什么」。配色与母题不是自由创作，而是沿用了作者在 RhineLabUI（莱茵终端）项目中已确认并验证过的基线，再迁移到长文阅读场景。

## 1. 原则

1. **档案感来自结构与字距，不来自特效数量。** 每加一个装饰，必须删掉一个。
2. **纸是暖的，字是黑的，强调是少的。** 彩色只承担"当前/可交互/编号"，不承担装饰。
3. **正文优先。** 元素视觉优先级：正文 > 代码 > 元数据 > 装饰。
4. **双模式不是反相。** 暗色重新调校，而不是把亮色变量取反。
5. **可访问性是硬约束。** 焦点可见、对比度达标、减少动态效果全量降级。

## 3. 字体

| 角色 | 字体栈 |
| --- | --- |
| 拉丁正文 / 中文 | `Roboto, "Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui` |
| 编号 / 微标签 / 终端 | `"JetBrains Mono Variable", "JetBrains Mono", "Cascadia Mono", Consolas, monospace` |

规则：

- 等宽字体只用于**编号、双语标签、坐标、状态**；正文绝不用等宽；
- 微标签 10–11px，`letter-spacing: .14–.24em`，全大写；
- 数字统一 `font-variant-numeric: tabular-nums`；
- 中文标题 `letter-spacing: -0.02em`，权重 750–800；正文行高 1.85。

## 4. 图形母题

| 母题 | 规则 | 落地位置 |
| --- | --- | --- |
| 刻度族 | 2px 宽；默认 12px，悬停 24px，当前 33px；400ms 过渡 | 阅读进度轨（≥1440px） |
| 发丝线 | 1px；线与线端 6×6px 方块 | 面板分隔、卡片头、页脚 |
| 状态方点 | 5×5px 实心方块 | 归档时间轴、状态行 |
| 检视角标 | 角部 L 形 1px 线 + 8px 方块 | 卡片右下角、404、封面四角 |
| 扫描环 | 同心圆 + 虚线环 + 十字准星 | 首页封面水印 |
| 刻度导航 | 2px 宽；12 / 24 / 33px；随滚动高亮；显示阅读百分比 | 文章页右侧（≥1440px） |
| 检索筛选 chip | 2px 圆角、1px 边界；选中反白；分类/标签计数 | 检索面板 |
| 数据条形 | 0.7rem 高、黄铜渐变、发丝线轨道；数值右对齐等宽 | 统计页月度/分类/标签 |
| 目录当前项 | 黄铜色 + 背景 tint + `▸` 前缀 + 加粗；`aria-current=location` | 文章页目录（滚动高亮） |
| 编号目录 | `01–NN` 两位编号 + 二级/三级缩进 + 当前项琥珀底色 | 文章页正文上方 |
| `X-001` 编号 | 三位补零，构建期按分页序号生成 | 文章卡片 |
| `EN / 中文` 标签 | 等宽大写 + " / " + 中文 | 元数据行、首页封面 |

## 5. 动效

| 场景 | 时长 / 曲线 |
| --- | --- |
| 卡片悬停 | 250ms `ease`，位移 −2px |
| 刻度变化 | 400ms `cubic-bezier(.22,1,.36,1)` |
| 扫描线（封面） | 7s 循环，`cubic-bezier(.45,0,.55,1)` |
| 状态脉冲 | 2.6s 循环 |
| 降低动态 | 全部 animation/transition 关闭 |

## 6. 布局

- 内容宽 `--page-width: 75rem`；侧栏 `17.5rem`；
- 卡片圆角统一 `3px`（`--radius-large`），按钮 2px——实验室器物感来自"小圆角 + 细边"，不是大圆角；
- 首页首屏：档案封面面板（标题 + 实时统计 + 扫描环水印）→ 文章卡片列表；
- 移动端：封面水印右移淡出、坐标隐藏、导航折叠。

## 7. 立即可用的扩展点

- 新增栏目：`src/config.ts` 的 `navBarConfig`；
- 新增侧栏部件：`layoutConfig.sidebar`（`profile / categories / tags / links`）；
- 换强调色：只改 `--rl-amber` 与 `--rl-amber-ink` 两组；
- 换图形风格：替换 `public/rhine/*.svg` 与 `RhineMark.astro`，CSS 无需改动。

## 离线与 Service Worker（评估结论：暂不启用）

Astro 静态站点可以很容易加 Service Worker 做离线缓存，但本模板**刻意不启用**：

1. **更新语义风险**：静态资源带 hash、Pagefind 索引与 `swup` 缓存叠加后，SW 很容易返回旧 HTML/旧索引，用户看到「已更新但内容没变」，排查成本高；
2. **收益有限**：本站以阅读归档为主，首次访问后浏览器 HTTP 缓存已能覆盖大部分重复访问；离线全文检索还需要额外缓存 Pagefind 分片，体积与复杂度都不小；
3. **模板定位**：这是一个可安装到他人博客的主题层，SW 注册会与目标站已有 SW 冲突，卸载/回滚也不如 CSS 覆盖层干净。

保留 `manifest.webmanifest` 与图标（安装到桌面/主屏仍可用），不注册 SW。若使用者确实需要离线阅读，建议在自己的站点层单独接入（如 Workbox），并自行处理版本失效策略。
