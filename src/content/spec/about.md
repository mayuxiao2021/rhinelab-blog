# 关于本站 / About

这里是 **莱茵档案（Rhine Archive）**，一座用「莱茵生命」视觉语言搭建的个人研究档案室。

## 我在记录什么

- **工程研究**：构建、部署、可复现性；
- **生命科学**：观测、记录、对照实验；
- **机构档案**：主题设计、排版规范、版本迭代。

每篇文章都尽量满足一个条件：**别人能照着复现**。不能复现的结论，只能算笔记，不算档案。

## 关于这套主题

本站同时是一套开源博客模板包的演示站点：

| 能力 | 说明 |
| --- | --- |
| 框架 | Astro 6 + Content Collections |
| 基座 | Fuwari（MIT），主题以覆盖层形式接入 |
| 检索 | Pagefind 静态全文索引 |
| 内容 | Markdown / KaTeX / Mermaid / 代码高亮 / 图片灯箱 |
| 设计 | 暖纸 + 墨色 + 黄铜，亮暗双模式，纯 CSS/SVG 图形 |
