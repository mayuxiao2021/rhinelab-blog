本站不是公告栏，而是一座**研究档案室**：每篇文章都是一份可检索、可追溯、可复现的档案条目。

## 为什么要"档案感"

大多数「科幻 / 游戏同人」博客会直接落到深色背景 + 霓虹描边 + 扫描线堆叠。它第一眼很抓人，但读三分钟后眼睛会累，长文尤其明显。这个主题反过来做：

- **纸是暖的**：背景取 `#eae5e1`，不是纯白，降低长时间阅读的眩光；
- **字是黑的**：正文墨色 `#080a08`，标题与数据用同一套墨，不靠彩色标题撑层次；
- **线是细的**：1px 发丝线、2px 刻度、6px 线端方块，构成档案的"结构感"；
- **强调是少的**：黄铜 `#9b7247` 只出现在编号、当前项、可交互焦点上。

> 设计基线不是拍脑袋：它沿用了同一位作者在「莱茵终端」UI 项目中已经定稿并验证过的暖纸 / 墨色 / 黄铜体系，博客只是换了介质。

## 主题由哪些"母题"构成

| 母题 | 用法 | 实现 |
| --- | --- | --- |
| 刻度族 | 阅读进度轨：默认 2×12，悬停 2×24，当前 2×33 | 纯 CSS + 少量 JS |
| 发丝线与线端方块 | 面板分隔、条目边界 | `border: 1px` + 伪元素 |
| 状态方点 | 状态标签、归档时间轴节点 | 5×5px 实心方块 |
| 检视角标 | 卡片角标、404 页 | 伪元素画十字与角 |
| 扫描环 | 首页封面水印 | SVG mask |
| `X-001` 编号 | 文章卡片、档案列表 | 构建期生成 |
| `EN / 中文` 双语标签 | 元数据行、导航 | 等宽字体 + 大写字距 |

## 技术底座（全部开源）

- [Astro](https://astro.build) 静态站点框架（MIT）+ Content Collections
- [Fuwari](https://github.com/saicaca/fuwari) 主题基座（MIT），本主题是其视觉覆盖层
- [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono)（OFL-1.1）用于编号与微标签
- [Roboto](https://fonts.google.com/specimen/Roboto)（Apache-2.0）用于拉丁正文
- [Pagefind](https://pagefind.app)（MIT）静态全文检索；KaTeX、Mermaid、PhotoSwipe 全部保留
